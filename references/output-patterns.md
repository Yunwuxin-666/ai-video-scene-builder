# 输出模式

## 完整场景包

默认顺序：

1. 一句话场景定义
2. 场景核心判断
3. 情绪线
4. 时长建议
5. 声音方案
6. 分镜脚本表
7. 素材准备清单
8. 镜头提示词
9. 可选图表建议

如果是 `Seedance` 请求，优先输出：

1. 一句话场景定义
2. 场景核心判断
3. 分镜脚本表
4. Seedance 分组提示词
5. 连续性或失败风险提醒
6. 可选模式说明：哪些镜头适合 I2V / V2V / R2V

## 默认分镜脚本表

当用户要分镜、场景脚本、镜头拆解时，默认使用这个固定列顺序：

| 镜头号 | 时长 | 景别 | 机位 | 画面内容 | 动作 | 情绪目的 | 声音提示 |
|---|---:|---|---|---|---|---|---|
| 1 | 3.6秒 | 远景 | 平视 | ... | ... | ... | ... |

规则：
- 提示词不要写进表格里
- 表格必须可读、可复制、可继续执行
- 除非用户明确只要粗版，否则不要用散点 bullet 代替表格
- `时长` 默认支持一位小数秒
- 优先写 `1.4秒`、`2.8秒`、`0.9秒` 这类更可执行的时长
- 不要把所有镜头机械写成 `.0秒`

## `画面内容` 的默认标准

`画面内容` 要足够清楚，能支撑后续：
- 写图像提示词
- 写视频提示词
- 检查动作逻辑
- 检查连续性

不要写成一句空泛摘要。

优先写清：
- 主体位置
- 主体初始出场方位
- 主体彼此的左右 / 前后 / 高低关系
- 谁更靠近镜头
- 环境状态
- 可见动作
- 受力点 / 命中点 / 反应
- 前景 / 中景 / 后景关系

如果是打斗、追逐、特效、奇幻、科幻、机甲镜头：
- `画面内容` 要帮助解决动作和调度，而不只是氛围
- 默认把角色调度写成硬约束，而不是模糊印象
- 至少交代：
  - 谁从哪个方向入镜
  - 谁占高位 / 低位
  - 谁在左前 / 右后
  - 谁挡住谁的路线
  - 镜头结束时站位有没有发生变化

如果镜头里有明显特效：
- 要尽量写清特效来源
- 特效形态
- 特效路径
- 特效落点或命中点
- 环境反馈
- 余波是否可见

## 时间建议

- 建立镜头：`2.5 - 4.5秒`
- 中景推进：`2.0 - 3.5秒`
- 近景情绪反应：`1.2 - 2.8秒`
- 特写动作细节：`0.8 - 2.0秒`
- 动作爆发 / 对撞 / 闪避：`0.6 - 1.8秒`
- 转身 / 回头 / 停顿：`1.0 - 2.5秒`

## 如果用户只要分镜脚本

输出：

- 一句话场景定义
- 情绪线
- 分镜脚本表
- 简短连续性提醒

如果场景里有：
- 打斗
- 追逐
- 奇幻能力
- 科幻战斗
- 机甲

那就额外把这些写清：
- 双方相对位置
- 出场方位
- 前后景层级
- 左右站位
- 高低关系
- 动作先后顺序
- 力量打在哪里
- 环境是背景还是危险

如果场景里有强特效：
- 粒子
- 烟雾
- 拖尾
- 火花
- 冲击波
- 装甲展开

不要只写“炫酷特效”，要把这些当成镜头事件的一部分写进去。

## 如果用户只要素材清单

按这个顺序输出：

1. 最先锁定什么
2. 需要哪些视觉参考
3. 需要哪些声音参考
4. 先做哪些关键帧
5. 后续再生成哪些视频片段

## 如果用户要教学拆解

输出：

1. 这场戏为什么成立
2. 它真正讲的是什么
3. 情绪递进
4. 如有必要，附分镜脚本表
5. 常见错误
6. 可选提示词示例

## 如果用户要 Seedance 输出

输出顺序：

1. 一句话场景定义
2. 场景核心判断
3. 分镜脚本表
4. Seedance 分组提示词
5. 连续性提醒

规则：
- 分镜表保持中文、可教学、可执行
- Seedance 提示词也默认用中文
- 优先按 `3-6秒` 分组
- 单段默认不超过 `15秒`
- 如果一组内容超过 `15秒`，必须继续拆分
- 默认不要写成一条全片长 prompt
- 动作组一定要把时间顺序写清楚
- 特效组一定要把来源 / 形态 / 路径 / 命中 / 环境反馈写清楚
- 中文成稿优先参考 `.claude/skills/seedance` 的措辞、模板和场景分类方式
- 不要使用英文公式说明来组织最终输出，优先直接写成中文成品提示词

## 如果用户要图表

优先考虑：

- 情绪线图
- 生产顺序图
- 场景结构图
- 连续性检查图
