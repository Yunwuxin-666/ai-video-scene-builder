# 输出模式

## 默认四块结构

除非用户明确只要某一部分，当前默认输出只使用这四块：

1. `【基础设定】`
2. `【氛围与画质】`
3. `【画面内容】`
4. `【完整分镜脚本表】`

不要默认额外输出：一句话场景定义、场景核心判断、情绪线、单独声音方案、素材清单、张力判断、张力增强层、镜头提示词、解释性分析或对话式说明。

这些判断仍然要在内部完成，但要融合进四块结构里。

## 高质量视频提示词输出

当用户要求 `视频提示词`、`即梦`、`Seedance`、`AI 视频生成`、`复刻提示词`、`高质量片段`、`分镜提示词`，或用户提供了“基础设定 + 氛围画质 + 画面内容分镜”这类参考格式时，优先使用本模式。

固定输出顺序：

```markdown
【基础设定】

角色1：
[身份 + 体型 + 时代/风格 + 自主意识/性格 + 脸部/表情系统 + 服装/机体/材质 + 固定道具]

角色2：
[对手/搭档/怪物/道具角色，写清体型、材质、行为特征、危险点或喜剧点]

场景：
[时代 + 地点 + 空间状态 + 可见道具 + 环境破坏 + 时间天气 + 叙事氛围]

声音：
[默认不要配乐，只保留现场声音、动作声、环境声、必要特效声]

【氛围与画质】

风格核心：
[3-6个强风格词，不要泛泛堆词]

视觉强调：
[摄影机/镜头/画幅/运动模糊/实拍质感/是否禁止廉价CG感]

色彩与影调：
[时代美学 + 主色组合 + 饱和度 + 胶片颗粒 + 高光暗部策略 + 材质清晰度]

视觉案例：
[把参考作品/IP转成中性可见风格，不直接写平台可能限制的专有名词，除非用户明确要求保留]

【画面内容】

分镜

分镜 1（00:00-00:03）【景别/镜头类型】
[机位 + 构图 + 画面先看到什么 + 主体动作 + 环境反馈 + 声音/特效重点]

【完整分镜脚本表】

| 镜头号 | 时间码 | 时长 | 景别 | 机位 | 画面内容 | 动作 | 情绪目的 | 声音提示 | 镜头功能 |
|---:|---|---:|---|---|---|---|---|---|---|
| 1 | 00:00-00:03 | 3.0s | ... | ... | ... | ... | ... | ... | ... |
```

## 分镜脚本表固定格式

如果用户明确说“只要表格 / CSV / Markdown 表格 / 只要分镜脚本表”，可以只输出表格。

默认字段顺序：

| 镜头号 | 时长 | 景别 | 机位 | 画面内容 | 动作 | 情绪目的 | 声音提示 | 全局提示词 | 细节增强提示词 |
|---|---:|---|---|---|---|---|---|---|---|
| 1 | 3.6秒 | 远景 | 平视 | ... | ... | ... | ... | ... | ... |

使用原则：

- 前 8 列负责分镜结构。
- `全局提示词` 负责整场戏统一的审美底座和技术质感。
- `细节增强提示词` 负责单镜头的局部材质、光影、环境和动态细节。
- 默认直接按完整 10 列输出，减少后续再补字段的返工。
- 如果用户明确只要轻量版，才允许临时压缩为前 8 列。

## `画面内容` 的默认标准

`画面内容` 不能只写成一句空泛摘要。它要足够支撑：

- 分镜阅读
- 出关键帧
- 写视频提示词
- 检查连续性
- 课堂讲解

推荐顺序：

1. 场景锚点
2. 主体人物出场方式
3. 人物层次 / 站位关系
4. 镜头先看到什么
5. 当前动作
6. 环境或特效反馈

如果是人物戏，优先写 `站位关系` 和 `视线关系`。
如果是动作戏，优先写 `运动方向`、`受力点` 和 `环境反馈`。
如果是爆点镜头，优先写 `反应主体`、`停顿点`、`压迫来源`。

## `声音提示` 的默认标准

默认只写：

- 对白
- VO / OS 的进入方式
- 环境声
- 动作声
- 必要特效声
- 声音反差
- 系统音、客服语音、AI 播报、故障提示、菜单提示、警报、设备运行声
- 静默、突停、延迟响应、机械重复、礼貌但无效的流程话术

默认禁止写：

- `背景音乐起`
- `配乐推进`
- `BGM燃起`
- `煽情音乐`
- `收尾音乐`
- `字幕音效`

## Seedance / 即梦输出

当用户明确要 `Seedance` 或 `即梦`：

1. 默认仍输出四块结构。
2. `【画面内容】` 使用带时间戳的分镜段落。
3. 每个时间戳分镜默认不超过 `15秒`，优先推荐 `4-8秒`。
4. `【完整分镜脚本表】` 只结构化同一批镜头，不新增剧情。

## 时间建议

- 建立镜头：`2.5 - 4.5秒`
- 中景推进：`2.0 - 3.5秒`
- 近景情绪反应：`1.2 - 2.8秒`
- 特写动作细节：`0.8 - 2.0秒`
- 动作爆发 / 对撞 / 闪避：`0.6 - 1.8秒`
- 转身 / 回头 / 停顿：`1.0 - 2.5秒`

## 出稿检查

- 是否直接从 `【基础设定】` 开始。
- 是否只输出四块结构，没有额外解释层。
- `【基础设定】` 是否锁住角色、场景、道具、声音。
- `【氛围与画质】` 是否写清摄影质感、镜头、光线、色彩、材质和廉价感规避。
- `【画面内容】` 是否每个分镜都有时间戳、景别/镜头类型、主体动作、环境反馈和声音重点。
- `【完整分镜脚本表】` 是否只结构化同一批镜头。
- 是否避免了“电影级、高质量、震撼”这类没有落地细节的空泛堆词。
