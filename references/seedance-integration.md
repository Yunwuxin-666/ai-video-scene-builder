# Seedance 联用说明

当用户明确要 `Seedance` 输出时，使用这份说明。

## 定位

`AIVideoPro` 仍然是上游主 skill。

它负责先产出：

- `【基础设定】`
- `【氛围与画质】`
- `【画面内容】`
- `【完整分镜脚本表】`

Seedance 输出属于下游适配层，负责：
- 按组输出片段级视频提示词
- 用中文方式整理成可直接使用的 Seedance 提示词

## 中文参考来源

后续只参考：

- `.claude/skills/seedance`
  - 作为 Seedance 中文输出模板来源
  - 重点参考它的：
    - 中文措辞
    - 模板化结构
    - 场景分类表达

固定边界：

- `AIVideoPro` 负责“镜头怎么成立”
- `.claude/skills/seedance` 负责“Seedance 中文怎么写得更像成品 prompt”

## 默认联用流程

1. 先完成四块结构。
2. `【画面内容】` 里按时间戳写分镜段落。
3. `【完整分镜脚本表】` 结构化同一批镜头。
4. 每个时间戳分镜默认控制在 `15秒` 以内，优先推荐 `4-8秒`。

更完整地说：

1. 用 `AIVideoPro` 产出四块结构
2. 从分镜表里抽取：
   - 画面内容
   - 动作
   - 情绪目的
   - 声音提示
   - 时长
3. 最终中文成稿参考 `.claude/skills/seedance` 的表达方式
4. 输出：
   - `【基础设定】`
   - `【氛围与画质】`
   - `【画面内容】`
   - `【完整分镜脚本表】`

## 映射规则

### 从分镜表到 Seedance 提示词

- `景别 + 机位`
  - 转成镜头类型 + 运镜表达

- `画面内容`
  - 转成主体 + 可见画面调度

- `动作`
  - 转成主动作节拍

- `情绪目的`
  - 决定动作密度、节奏快慢和风格收放

- `声音提示`
  - 转成音频层提示

- `时长`
  - 决定这一组提示词是简单片段，还是要写成更明确的时间顺序

## Seedance 提示词结构

默认优先使用中文分段式写法：

`【镜头类型】+【主体】+【动作】+【风格】+【运镜】+【声音提示】`

其中默认映射为：

- `景别 + 机位` -> `镜头类型 + 运镜`
- `画面内容` -> `主体 + 可见画面调度`
- `动作` -> `动作`
- `情绪目的` -> `节奏密度 + 风格收放`
- `声音提示` -> `声音提示`
- `时长` -> `片段长度与时间顺序`

## 默认规则

- 一组片段尽量只承载一个主动作，或一组紧密相连的动作节拍
- 默认不要把整场戏塞进一条超长提示词
- 每段 Seedance 提示词默认不超过 `15秒`
- 更稳的推荐区间是 `4-8秒`
- 动作戏必须写清楚时间顺序
- 特效戏必须写清楚来源、形态、路径、落点和环境反馈
- 上游分镜表保持中文、可教学、可执行
- 下游 Seedance 提示词也默认用中文输出，除非用户明确要求英文
- 中文输出优先参考 `.claude/skills/seedance` 的成稿风格

## 默认交付形态

如果用户明确要 Seedance，默认最终交付不是“一整场戏一条长 prompt”，而是：

1. `【基础设定】`
2. `【氛围与画质】`
3. `【画面内容】`
4. `【完整分镜脚本表】`

默认要求：
- 每组提示词都在 `15秒` 以内
- 如果单组超过 `15秒`，必须继续拆组
