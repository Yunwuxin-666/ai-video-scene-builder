# 时长.skill

## Routed Mode

当输入包含 FilmSpec 或制片交接时：

- 只修改 `duration_patch`、时间码、节奏曲线和切点。
- 按镜头 ID 返回 patch。
- 不重新生成主体、动作、镜头、灯光、风格或完整提示词。
- 如果既定动作无法在时长内清楚完成，报告密度冲突，由制片层决定拆镜或改范围。
- 4–8 秒是安全分段默认值，不是平台无关的硬限制。

只有用户单独调用本 skill 时，才使用后面的完整输出模式。

## Mission

把创意、脚本、分镜表或已有视频节奏，转成可拍、可剪、可生成的镜头时长方案。优先判断每个镜头承担的信息、动作、情绪和剪辑功能，再决定秒数。不要把时长当成平均分配。

## Load References

- 需要按场景给镜头时长区间、节奏曲线、广告/剧情/悬疑/动作/产品等规则时，读同目录 `duration-rules.md`。
- 需要检查用户已有分镜、拉片表、AI 视频片段是否节奏失衡时，读同目录 `duration-audit-checklist.md`。
- 需要输出可复制的 AI 视频提示词、逐镜头时长提示词、负面提示词时，读同目录 `duration-prompt-templates.md`。

## Core Workflow

1. 先判断片子类型：广告、剧情、悬疑、动作、教育咨询、产品展示、人物成长、纪录片、AI 视频生成片段，或混合类型。
2. 判断总时长与平台：15 秒、30 秒、60 秒、90 秒、3 分钟；横屏、竖屏、信息流、课程片头、品牌短片、剧情短片。
3. 给出节奏骨架：开场抓问题、冲突展开、方法/产品进入、证明或转折、结果与收束。
4. 给每个镜头一个功能，而不是只给景别：建立空间、给信息、完成动作、制造等待、确认反应、证明产品、落下后果、转场。
5. 按功能决定时长：
   - 信息镜头短，情绪镜头长。
   - 动作镜头要让动作完成后再切。
   - 产品证明不能短到看不清。
   - 悬疑镜头要比观众预期多停一拍。
   - 对话镜头通常切在听懂、犹豫、压住情绪或反应发生的瞬间。
6. 标注切点理由：cut on motion、eye-line cut、sound bridge、reaction hold、impact cut、match cut、ending hold。
7. 检查是否过碎或过拖。过碎时合并相邻同功能镜头；过拖时拆出动作点、信息点或反应点。
8. 如果用于 AI 视频，默认单条片段控制在 4-8 秒；复杂动作拆成多个可独立生成的镜头，每条只承载一个主要动作。

## Output Modes

### 时长铺排

用于用户给主题、脚本、广告想法或粗分镜，需要分配秒数。

输出：

1. `节奏判断`: 说明这条片子应该快、慢、快慢交替，还是前慢后快。
2. `总时长骨架`: 用时间段说明每一段承担什么任务。
3. `逐镜头时长表`: 镜号、时间码、秒数、画面动作、镜头功能、切点、节奏理由。
4. `风险提醒`: 哪些镜头容易太短看不清、太长拖节奏、或切点无动机。
5. `AI 生成提示词`: 每个镜头给可复制提示词时，必须包含时长、主体、动作、场景、景别、机位、焦段、运镜、焦点和切点。

### 时长检查

用于用户已有分镜表、脚本、时间码或剪辑节奏，需要诊断。

输出：

1. `总体问题`: 判断节奏是碎、拖、平、跳、乱，还是产品/情绪/动作没被看见。
2. `逐镜头诊断表`: 原时长、建议时长、问题、修改原因。
3. `必须保留的停顿`: 哪些地方不能压短，因为承担情绪、悬疑、反应或产品证明。
4. `可以合并的镜头`: 哪些相邻镜头功能重复。
5. `重排后版本`: 给一版可直接替换的时间码表。

### 拉片时长分析

用于分析参考片节奏。

输出：

1. `节奏曲线`: 哪些地方加速、减速、停顿。
2. `平均镜头时长`: 粗略估计即可，除非用户提供视频文件或精确时间码。
3. `关键切点`: 动作切、声音切、反应切、信息切。
4. `可复用机制`: 说明可以借鉴的时长结构，不照搬表面画面。

## Duration Principles

- 0.3-0.8 秒：撞击、闪回、危险提示、极短插入，不负责完整叙事。
- 0.8-1.5 秒：产品细节、手部动作、表情闪现、快剪信息点。
- 1.5-3 秒：广告常用主镜头、动作完成、人物转身、产品使用。
- 3-6 秒：对话、观察、情绪反应、空间建立。
- 6-12 秒：悬疑等待、压迫、复杂走位、心理变化。
- 12 秒以上：一镜到底、纪录片观察、仪式感、强沉浸场景。

这些不是硬规则。真正的判断顺序是：信息可读性、动作完整性、情绪停顿、剪辑点力量。

## Hard Boundaries

- 不要平均分配镜头时长。
- 不要为了显得高级，把所有镜头都切成短句式快剪。
- 不要为了情绪感，把没有心理变化的镜头拖长。
- 不要让产品、手部操作、关键 UI、学习诊断、证据细节一闪而过。
- 不要把 AI 视频单条提示词写得动作过多；一条片段只承载一个主要动作。
- 不要只说“节奏快一点/慢一点”，必须给秒数、切点和原因。
- 不要只给表格。表格后要解释这条片子的节奏逻辑。

## Quality Bar

完成前检查：

- 每个镜头是否有明确功能。
- 每个时长是否能被动作、信息、情绪或剪辑点解释。
- 开场 3 秒是否有抓手。
- 中段是否有节奏变化，而不是平均速度。
- 产品/方法/人物判断是否被看见。
- 情绪镜头是否真的发生变化。
- AI 视频片段是否可以独立生成，且单条动作不过载。
