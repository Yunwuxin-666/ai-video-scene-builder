# Prompt Templates

Use these templates when the user needs copy-ready prompts.

## Full Sound Design Prompt

```text
为一段【场景类型】设计电影级音效和背景音乐。

画面内容：【时间、地点、人物、动作、镜头节奏】
情绪目标：【紧张/温暖/高级/孤独/热血/神秘/悲伤/压迫/清晰/荒诞】

音效层：
1. 环境底噪：【空间、天气、机器、城市、自然、房间空气】
2. 动作拟音：【脚步、呼吸、衣料、道具、车辆、触碰、界面】
3. 情绪声音：【低频、心跳、耳鸣、反向音、金属摩擦、空气抽离、静音】
4. 转场声音：【whoosh、riser、impact、glitch、sound bridge、hard cut silence】

BGM 要求：
使用【乐器/风格/音色】，速度【BPM 或慢/中/快】，节奏密度【稀疏/中等/强推进】，旋律密度【无旋律/少量动机/明确主题】。
音乐从【入点】开始，在【增长点】增加【低频/节奏/和声/乐器】，在【落点】形成情绪确认，并在【退出点】以【淡出/硬切/留白】结束。

混音优先级：
【对白/旁白/产品动作/环境真实感/音乐情绪】优先，避免音乐盖住关键信息。

负面约束：
不要【廉价惊吓/过度史诗/流行歌感/企业宣传片大鼓/卡通音效/过满混音/明显模板库音效】。
整体听感：【一句话描述声音完成后的观感】
```

## Music-Only Prompt

```text
生成一段适合【场景/广告/短片】的背景音乐。

情绪功能：【音乐要推动什么叙事功能】
风格参考机制：【极简电子/低音钢琴/弦乐 drone/indie folk/ambient pad/industrial percussion】，只参考音色和结构，不复制任何旋律。
乐器配置：【主乐器、低频、节奏、点缀乐器】
速度与节奏：【BPM、节奏密度、是否需要鼓点】
旋律要求：【无明显旋律/短动机/克制主题/开阔主题】
结构：【开场 0-5 秒、中段 5-20 秒、结尾 20-30 秒】
混音：【低频控制、空间感、是否给旁白留频段】
避免：【不需要的风格和情绪】
```
