# Duration Rules

## Basic Timing Ranges

| 时长 | 用途 | 判断标准 |
|---|---|---|
| 0.3-0.8 秒 | 闪回、撞击、危险提示、快速插入 | 只给刺激，不承担完整叙事 |
| 0.8-1.5 秒 | 产品细节、手部动作、快剪信息 | 观众能识别主体即可 |
| 1.5-3 秒 | 广告主镜头、动作完成、转身、使用 | 信息和动作都能读清 |
| 3-6 秒 | 对话、情绪反应、空间建立 | 观众能进入关系和心理 |
| 6-12 秒 | 悬疑、压迫、复杂走位、心理变化 | 等待本身成为内容 |
| 12 秒以上 | 一镜到底、纪录片观察、仪式感 | 连续时间制造沉浸 |

## Scene-Specific Rules

### Opening / Establishing

- 广告开场：1.5-4 秒。先给问题、动作或反差，不要只给漂亮空镜。
- 剧情开场：4-8 秒。让观众知道空间、人物位置和气氛。
- 悬疑开场：6-12 秒。用等待建立不安。

### Dialogue

- 普通对话：2-4 秒。
- 争吵：1-2.5 秒，可用更碎的反应切。
- 试探、谈判、暧昧：3-6 秒，重点在停顿和听懂。
- 重要沉默：5 秒以上，但画面里必须有心理变化。

切点优先级：说完话不是唯一切点；更好的切点常在对方听懂、眼神躲开、手停住、呼吸变化、压住情绪的一刻。

### Action / Chase / Fight

- 撞击瞬间：0.3-0.8 秒。
- 单个完整动作：1.2-3 秒。
- 复杂走位：4-8 秒，优先用连续镜头保护空间。
- 后果镜头：1-3 秒，给重量。

动作戏先保证方向、距离、身体关系和接触点，再考虑快剪。

### Suspense / Horror / Pressure

- 空间铺垫：5-10 秒。
- 可疑细节：1-2 秒。
- 人物察觉：3-6 秒。
- 突然揭示：0.5-1.5 秒。
- 揭示后的反应：3-8 秒。

悬疑的时长来自延迟。观众刚开始怀疑时不要立刻揭示。

### Product / Commercial

- 痛点镜头：1.5-3 秒。
- 使用动作：2-4 秒。
- 产品细节：0.8-2 秒。
- 前后对比：2-5 秒。
- 品牌收尾：1.5-3 秒。

产品证明必须看得清：手怎么操作、界面出现什么、结果如何变化。复杂 UI 和文字建议后期添加。

### Education / Consulting / Course

- 学生或客户困惑：2-4 秒。
- 咨询师观察：3-5 秒。
- 关键诊断动作：3-6 秒。
- 白板、资料、路径图：2-4 秒。
- 家长、学生或客户反应：2-5 秒。

这类片子卖的是判断力，不是热闹。诊断镜头不能过短。

### Character Growth

- 日常动作：2-4 秒。
- 失败瞬间：3-6 秒。
- 孤独停顿：5-10 秒。
- 蒙太奇：0.8-2 秒。
- 最终选择：4-8 秒。

成长片靠时间痕迹。重复、停顿、犹豫、重新开始，比口号更有用。

## Rhythm Structures

### 15-Second Ad

| 时间段 | 功能 |
|---|---|
| 0-2 秒 | 问题或反差 |
| 2-6 秒 | 冲突扩大 |
| 6-11 秒 | 产品/方法进入并证明 |
| 11-15 秒 | 结果、情绪、品牌 |

### 30-Second Ad

| 时间段 | 功能 |
|---|---|
| 0-3 秒 | 抓住问题 |
| 3-10 秒 | 展开冲突 |
| 10-20 秒 | 产品/方法进入 |
| 20-26 秒 | 结果出现 |
| 26-30 秒 | 收束与品牌 |

### 60-Second Story Ad

| 时间段 | 功能 |
|---|---|
| 0-5 秒 | 人物和冲突 |
| 5-18 秒 | 问题具体化 |
| 18-35 秒 | 方法、产品或关键选择 |
| 35-50 秒 | 变化被看见 |
| 50-60 秒 | 情绪收束和品牌 |

## Average Shot Duration Guide

| 类型 | 平均镜头时长 |
|---|---|
| 快节奏信息流广告 | 1-2.5 秒 |
| 普通商业短片 | 2-4 秒 |
| 人物剧情短片 | 3-7 秒 |
| 悬疑短片 | 4-10 秒 |
| 动作短片 | 0.5-4 秒交替 |
| 纪录片观察 | 5-15 秒 |

平均值只能用来检查整体节奏，不能用来平均分配每个镜头。
