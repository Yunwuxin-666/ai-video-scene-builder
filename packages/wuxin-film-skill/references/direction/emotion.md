# 情绪.skill

## Mission

把提示词里的“抽象情绪词”改成能被镜头拍到、能被演员表演、能被 AI 视频模型稳定生成的情绪表现。重点检查人物情绪是否落到动作、身体、眼神、空间关系、镜头距离、光线、声音和节奏上。

不要只把提示词写得更文学。情绪优化必须服务画面可执行性。

## Core Principle

影视情绪不是写“他很悲伤 / 她很紧张 / 氛围很高级”，而是设计一个观众能看见的瞬间：

- 人物想要什么；
- 人物害怕什么；
- 人物怎样忍住、靠近、退缩、停顿、错开视线；
- 空间如何压迫、隔开、包住或释放人物；
- 镜头和声音如何让观众进入这个情绪。

## Workflow

1. 识别场景功能：压迫、悬疑、孤独、悲伤、愤怒、羞耻、亲密、欲望、希望、释然、荒诞、震撼、麻木、释放，或用户自定义情绪。
2. 找出原提示词里最薄弱的情绪问题：只有情绪标签、动作太泛、表演太夸张、空间不支持情绪、镜头距离错误、声音缺失、情绪和产品/剧情无关、一个镜头塞了多种情绪。
3. 保留原始主体、人物身份、场景、动作、产品、视觉风格和叙事目标。只优化情绪表达、表演细节、情绪调度、镜头贴近方式、声音和负面约束。
4. 把抽象词替换成可见动作。优先使用微动作：停顿、吞咽、手指摩擦、眼神错开、肩膀收紧、放下物件、没有立刻回应、把话咽回去。
5. 用空间和镜头加压或释放：前景遮挡、门框/玻璃/桌面阻隔、长焦压缩、负空间、固定镜头、缓慢推近、从近到远、从手持到稳定。
6. 加入声音锚点：空调低频、碗筷声、纸张摩擦、远处电梯、雨声、冰柜嗡鸣、键盘声、风声。声音要和情绪有关，不要堆氛围词。
7. 输出可直接复制的优化提示词，并附上负面提示词，禁止常见失败：夸张表演、哭喊、油腻微笑、空洞发呆、廉价惊吓、漂浮 UI、无意义慢动作、过度滤镜、情绪和动作脱节。

## Diagnosis Checklist

检查提示词时，直接指出 1-5 个关键问题，不要泛泛点评。

- 情绪是否只是标签，而没有动作证据？
- 人物是否有明确的欲望、阻力或关系压力？
- 表演是否过满：大哭、怒吼、尖叫、夸张皱眉、摆拍式凝视？
- 情绪是否能在 4-8 秒短镜头里成立？
- 一个镜头是否塞了太多动作或情绪转折？
- 镜头景别和焦段是否匹配情绪：压迫用更近或长焦，孤独用空间隔离，亲密用关系同框，释放用开阔空间？
- 环境是否在帮情绪：会议室、医院、饭桌、教室、便利店、走廊、天台、办公室各自的压力来源是否清楚？
- 声音是否提供了现实抓手？
- 是否有 AI 视频常见风险：人物发呆、表情塑料、手部变形、镜头乱晃、场景跳变、文字不可读？

## Emotion Translation Rules

把常见情绪翻译成可拍表现：

- 压迫：手指摩擦、吞咽、坐姿收紧、被前景人影挡住、长桌尽头、空调低频。
- 悬疑：先听见异常，再看到反应；门缝光、停住的手、延迟揭示、环境声放大。
- 孤独：热闹中静止、隔着玻璃、人物被空间切开、世界继续运转但没有回应他。
- 悲伤：继续完成日常动作，但动作失去意义；拿出两只碗又放回一只。
- 愤怒：沉默、动作变精确、眼神固定、轻轻放下物件，比怒吼更危险。
- 羞耻：被看见、被沉默包围、想折起试卷/藏起物件、视线压力。
- 亲密：不用解释的小动作，递水、调暗灯、盖毯子、两人共享沉默。
- 欲望：身体轻微前倾、目标物更亮更清晰、人物处在稍暗位置。
- 希望：从卡住到重新开始；开窗、换新纸、重新拿起工具，空间变松。
- 释然：完成告别动作；合上盒子、放回照片、关门、把钥匙留在桌上。
- 荒诞：人物极认真，处境极不合理；固定镜头、冷静观察、停顿留白。
- 震撼：小人物面对大空间、大系统或自然力量；少对白，给空气。
- 麻木：机械重复、表情很少、时间被拉长、冷静固定镜头。
- 释放：身体从收缩到展开；从压迫镜头转为开阔镜头，声音打开。

## Output Format

默认用这个结构，除非用户要求只给最终提示词：

```markdown

- ...

## 优化方向
- ...

## 优化后提示词
```text
...
```

## 负面提示词
```text
...
```
```

如果用户给的是分镜表，逐镜头输出：

```markdown
| 镜头 | 情绪问题 | 优化后画面内容 / 提示词 | 负面约束 |
|---|---|---|---|
```

## Prompt Writing Standard

优化后的提示词至少包含：

- 稳定人物：年龄、性别/身份、服装、发型或关键道具；
- 单一可见动作：一个镜头里只让人物完成一个主要动作；
- 情绪动作：微表情、手部动作、停顿、视线、身体姿态；
- 场景和时间：地点、时间、空间关系；
- 镜头：景别、机位、焦段、运动、焦点；
- 光线和色彩：只写和情绪有关的光，不堆“高级感”；
- 声音：1-3 个现实声音锚点；
- 情绪关键词：放在提示词后部，作为统领；
- 负面约束：禁止最可能生成失败的表演、镜头和画面问题。

## Hard Boundaries

- 不要改掉用户原本的剧情目的、产品功能、人物关系和场景设定，除非用户要求重构。
- 不要把情绪优化写成心理分析长文；要回到画面。
- 不要为了“情绪强”添加大哭、怒吼、尖叫、拥抱、跪地、摔东西等廉价动作。
- 不要让每个提示词都变成雨夜、便利店、地铁、咖啡、凌晨办公室。只有当这些场景服务情绪时才使用。
- 不要同时塞多个情绪弧线进一个 4-8 秒镜头。复杂情绪要拆镜头。
- 不要生成长段可读文字、精确 UI 文案、复杂屏幕内容。文字和字幕建议后期添加。
- 不要用“电影感、高级、氛围拉满、情绪张力强”替代具体镜头证据。

## Example

用户原提示词：

```text
一个男人在会议室里很紧张，电影感，高级，压迫。
```

优化：

```text
一名30岁男性坐在会议室长桌尽头，白衬衫微皱，双手交握放在桌面，指节轻轻摩擦，想开口却停住。下午的封闭会议室，百叶窗切出窄条光影，桌面有水杯和文件夹。镜头为70mm中近景，机位略低于眼平，从桌子另一端极慢推近，T2.8浅景深，前景虚化出模糊的人影肩膀，人物被压在画面中央偏下。环境声只有空调低频、纸张翻动声和水杯被轻碰的声音。情绪克制、紧张、被审视、即将失控。避免夸张皱眉、避免怒吼、避免人物空洞发呆、避免无意义镜头乱晃。
```
