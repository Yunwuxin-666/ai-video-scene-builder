# 角色设计

## Mission

把用户的角色想法转成可执行的角色设计方案和提示词。先建立世界观、角色功能、身体比例和视觉母题，再设计服装、妆造、道具、材质和特效。目标不是做一套“好看的衣服”，而是做一个能进入影视/动画/游戏世界、远中近景都能被识别的角色。

默认中文输出。输出要能直接用于 AI 图像生成、角色设定图、服装拆解图、材质道具图。

## Core Rule

不要从服装款式开始。按这个顺序工作：

```text
世界观 -> 角色身份 -> 身体比例/形态 -> 行动方式 -> 视觉母题 -> 服装功能 -> 材质系统 -> 妆造道具 -> 风格表现 -> 输出图类型
```

角色成立的判断标准：

- 远景能读出剪影和身份。
- 中景能读出职业、阵营、阶层和行动方式。
- 近景能读出材质、工艺、旧化、妆造和私人物件。
- 服装必须挂在身体和世界观上，不能只是装饰。

## Reference Loading

按任务读取参考文件，不要一次性读取全部：

- 用户要多种风格、世界观路线、正反派对照、仙侠/武侠/写实CG/国漫/皮克斯/IP潮玩：读 `references/style-routes.md`。
- 用户要可复制提示词、三视图、服装拆解图、材质小样、道具图、特效增强版：读 `references/prompt-templates.md`。
- 用户要求服装精度接近影视/游戏角色装备设定、参考图包含甲胄、铆钉、兽首肩甲、鳞甲、皮革束带、织锦暗纹、旧化金属、配件拆解：读 `references/costume-precision.md`。

## Workflow

1. 先识别输出类型：角色设定图、服装拆解图、妆造图、道具材质图、正反派组合、风格探索、提示词修复。
2. 提炼角色核心：一句话写清“这个角色是谁，在什么世界里，以什么方式生存或战斗”。
3. 决定身体比例和形态：
   - 写实CG/影视：7.5-8头身，真实骨架和材质重量。
   - 国漫/游戏PV：6.5-8头身，剪影、色块、飘带和武器可夸张。
   - 皮克斯/IP潮玩：4.5-5.5头身，头大身小，圆润剪影，适合手办化。
   - 怪物/异形：先定角、尾巴、甲壳、多臂、兽足等身体结构，再设计披挂和服装。
4. 设计视觉母题。母题必须贯穿轮廓、纹样、材质和道具。例如霜莲、玄鸦、青玉书剑、竹木机关、蛇鳞禁军、琉璃蝶刃。
5. 设计服装层级：内搭、外袍/外套、腰封、护腕/甲片、鞋靴、披风/披挂、头饰、随身道具。
6. 设计材质系统。至少给 3-5 个明确材质，并描述它们如何受光：吸光、透光、折射、反光、氧化、磨损、起毛、压纹。
7. 设计妆造：发型、眉眼、肤色质感、面部标记、头饰、表情状态。妆造要服务身份和世界观。
8. 如需高精度服装，必须写出连接逻辑：甲片如何固定，腰封如何穿插，皮带如何受力，铆钉/扣具/缝线/包边在什么位置，纹样集中在哪里，旧化发生在哪些边缘。
9. 如需特效，特效必须有来源、材质、受力、接触和收束。不要空中乱飘光效。
10. 输出时优先给可复制提示词；复杂任务可先给设计判断，再给提示词。

## Output Modes

### Single Character

输出：

1. `设计判断`：一句话说明角色母题和为什么这样设计。
2. `角色设定提示词`：包含世界观、身份、比例、服装、妆造、材质、道具、风格。
3. `服装拆解图提示词`：白底、无人物、只有服装和配件。
4. `负面提示词`：避免常见生成失败。

### Character Pair / Faction Contrast

用于男主/反派、师徒、门派、阵营组合。输出必须拉开：

- 剪影；
- 色彩；
-材质；
- 武器/道具；
- 站姿和气质；
- 世界观权力位置。

### Prompt Repair

先指出为什么平，再修：

- 是否只有衣服，没有角色？
- 是否没有母题？
- 是否远景剪影弱？
- 是否材质和特效没有机制？
- 是否妆造没有身份信息？

然后给重写版本。不要只加“更华丽、更精致”等空词。

## Design Heuristics

- 美艳不等于暴露；用骨相、仪态、材质、剪影和眼神做美感。
- 温柔不等于柔弱；用动作收束、色彩克制、布料垂坠和表情稳定来表现。
- 反派不等于黑衣邪笑；用直线剪影、冷材质、礼法符号、权力道具制造压迫。
- 修仙角色不能只写“仙气”；要有宗门身份、功法母题、法器、灵气来源和战斗逻辑。
- IP潮玩不能只是写实缩小；要有大轮廓、少而准的职业符号、圆润比例和可手办化部件。
- 怪物服装不能套人类模板；根据角、尾、翅、甲壳、多臂、兽足重新设计开口、束带、披挂和护甲。

## Negative Constraints

常用负面提示词可按任务改写：

```text
避免廉价cosplay、避免网红古装写真、避免影楼风、避免塑料金属、避免布料无褶皱、避免材质混乱、避免随机纹样、避免过度发光、避免漂浮UI、避免文字乱码、避免logo水印、避免身体比例错误、避免额外手指、避免服装穿模、避免背景杂乱。
```
