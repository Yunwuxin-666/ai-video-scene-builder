# 角色设计提示词模板

## 角色设定图模板

```text
[风格类型]角色设定图，白灰干净背景，一名[年龄/性别/身份]，[头身比例/身体形态]，[身形和站姿]。[世界观一句话]，角色是[职业/阵营/剧情功能]，视觉母题为“[母题1、母题2、母题3]”。整体气质[3-5个气质词]。

服装为[内搭]，外搭[外层服装]，[领型/袖型/肩部/腰部/下摆结构]。[腰封/甲片/披风/披挂/鞋靴]体现[行动方式/身份等级]。[武器/法器/道具]与角色能力相关。

妆造为[发型/头饰/面部标记/妆容/表情]。材质表现重点：[材质1如何受光]，[材质2如何受光]，[材质3如何受光]，[材质4如何受光]。输出为角色三视图，包含正面全身、背面小图、侧面小图、头部妆造特写、关键道具、服装结构和材质小样。
```

## 服装拆解图模板

```text
[角色名/服装名]服装拆解图，白色纯背景，只有服装本体和配件，无人物、无模特、无人台、无场景。拆解展示[内搭]、[外袍/外套]、[腰封]、[护腕/甲片]、[鞋靴]、[头饰]、[武器/道具]。清晰表现[领型]、[袖型]、[侧开衩]、[腰封穿插方式]、[裁片分割线]、[刺绣/纹样]、[金属扣件]、[皮革磨损]、[布料纤维]、[材质小样]。高级角色服装技术设定图，白底留白，无可读文字。
```

## 特效增强模板

```text
[风格类型]角色展示图，白灰干净背景，[角色]正在[一个可见动作]。[特效]来源明确来自[法器/腰封/武器/纹样/机关]，由[材质]组成，受[动作/风/灵气/机关/重力]驱动，并与[衣料/头发/武器/地面/空气]产生真实互动。[特效]照亮或影响[刺绣/金属/玉石/纱/皮革]，最后在[位置]收束。整体特效克制清晰，不遮挡角色主体。
```

## 正反派对照模板

```text
请设计一组[题材]正反派角色。

男主/正派：[身份]，[比例]，[母题]，[服装轮廓]，[材质]，[武器]，[气质]。
反派：[身份]，[比例]，[母题]，[服装轮廓]，[材质]，[武器/权力道具]，[气质]。

要求两人从剪影、色彩、材质、武器、站姿和世界观权力位置上明确拉开。分别输出角色设定提示词、服装拆解图提示词和统一负面提示词。
```

## IP潮玩模板

```text
高端IP潮玩手办设计图，一个[身份/职业]，[4.5-5.5头身比例]，头大身体小，轮廓圆润，表情[性格]。世界观为[世界观]，视觉母题为“[母题]”。角色穿[简化服装]，身上有[3-5个职业符号道具]，最强记忆点是[可手办化大部件]。材质为哑光PVC、半透明树脂、仿木纹涂装、旧铜金属漆、棉麻褶皱雕刻。白色纯背景，正面、背面、侧面、表情和道具拆解展示。
```
