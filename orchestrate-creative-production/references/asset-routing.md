# Asset routing

## Retrieval order

1. Current project brief and locked decisions
2. Current project assets and approved outputs
3. Explicitly linked historical project assets
4. Relevant skills, templates, and style cards
5. Broader external research only when needed

Prefer the most specific source. When sources conflict, do not blend silently; surface the conflict to the main agent.

## Storage decision

| New information | Store in | Do not store in |
|---|---|---|
| Character anatomy, clothing, props | Character asset pack | Global visual rules |
| Named reusable aesthetic | Triggered style card | Default genre rules |
| One reference image's incidental detail | Project notes | Shared style card |
| Repeated working method | Skill or workflow | One-off prompt log only |
| Repeated delivery structure | Template | Skill body when a template suffices |
| Failure and successful correction | QA rules | Generic preferences |
| Course-specific explanation | Course document | Production protocol |

Record asset name, purpose, source path or URL, trigger, status, known strengths, failure modes, and related examples.
