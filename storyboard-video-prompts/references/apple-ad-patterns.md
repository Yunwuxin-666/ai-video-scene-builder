# Apple Ad Pattern Reference

Use this reference only when the task specifically asks for Apple-style commercials, iPhone/iPad/Mac/Watch inspired shorts, or a similar restrained product-ad rhythm.

## Main Mechanisms

### Big Problem, Small Action

Make the visible problem large, specific, and easy to understand. Solve it with one small product action. Examples of the mechanism:

- Lost phone in a haystack -> tap Apple Watch to ping it.
- Long day / repeated task -> battery quietly lasts.
- Hard-to-capture moment -> camera catches it without drama.

The product action must feel lighter than the problem.

### Feature as Scene, Not Feature as Explanation

Translate each technical feature into a physical scene:

- Wide lens -> a cramped group photo becomes possible.
- Cinematic focus -> a detective scene shifts attention between characters.
- Privacy -> invisible tracking becomes visible pursuit.
- Durability -> a comic accident proves resilience.

Avoid feature lists. Pick one spine.

### Ordinary World, Precise Twist

Use ordinary settings with a precise twist: farm, school play, kitchen, commute, family table, office, street corner, library. The contrast between ordinary life and elegant tool action creates the brand feeling.

### Restraint

Apple-like restraint is not emptiness. It means:

- Few props, all meaningful.
- Few words, all necessary.
- Product appears late or quietly.
- End card is short.
- Sound design is clean and memorable.

## Rhythm Template For 60 Seconds

| Segment | Time | Function |
|---|---:|---|
| Hook | 0-5s | Show a concrete situation or odd problem. |
| Problem build | 5-18s | Make the task feel real and slightly difficult. |
| Tool appears | 18-28s | Product enters as a natural next action. |
| Action chain | 28-45s | Use motion matches, sound cues, or montage to show the tool working. |
| Result | 45-55s | Let the human outcome land. |
| End card | 55-60s | One line, product/brand implication, no over-explanation. |

## Useful Imitation Boundaries

Do not copy Apple logos, exact product UI, campaign taglines, or protected shots. Borrow the structure:

- Simple human problem.
- Elegant tool behavior.
- Dry humor or quiet emotional release.
- Clean visual grammar.

When creating for another brand or a fictional product, make the world and object distinct.
