# 分镜脚本模板

默认分镜输出优先使用下面这张表。  
除非用户明确只要粗版大纲或松散思路，否则不要改成普通 bullet list。

## 要求

- `时长` 默认支持 `0.1秒` 粒度，优先允许写成 `2.4秒`、`3.2秒`、`0.8秒`
- 不要默认把所有镜头都四舍五入成整数秒
- 也不要机械地把所有镜头都写成 `.0秒`
- `画面内容` 不能只写成一句空泛摘要
- `画面内容` 要能支撑后续出图、出视频、做课件

`画面内容` 尽量写清：
- 人物是谁，在画面什么位置
- 人物从哪个方向出场
- 人物彼此在左 / 右 / 前 / 后 / 高 / 低的关系
- 谁更靠近镜头
- 环境在做什么
- 镜头里先看到什么
- 具体动作或结果是什么

如果是打斗、追逐、特效、机甲、奇幻、科幻场景，`画面内容` 还要尽量写清：
- 角色初始站位和结束站位
- 特效从哪里出现
- 特效是什么形态
- 特效往哪里走
- 特效打到哪里
- 特效造成了什么环境反馈
- 人物相对位置
- 动作方向
- 攻击或受力点
- 环境是否构成危险
- 前景 / 中景 / 后景里最重要的视觉关系

## 补充规则

- `镜头提示词` 不放在这张表里，单独放在后面的提示词部分
- 如果用户明确要 `Seedance 2.0`，分镜表仍然保留，后面再单独写 `Seedance 分组提示词`
- `情绪目的` 尽量写清这个镜头为什么存在，而不是只重复画面内容
- `声音提示` 只写关键声音，不要把完整配乐方案塞进表格
- 如果后面要给 AI 出图或出视频，优先先把 `画面内容` 写扎实，再去写提示词
- 如果镜头涉及粒子、烟雾、火花、余波、拖尾、装甲展开、冲击波，不要只写“有特效”，要尽量写清它们的来源、运动和落点

## 可参考的默认时长范围

- 建立镜头：`2.5 - 4.5秒`
- 中景推进：`2.0 - 3.5秒`
- 近景情绪反应：`1.2 - 2.8秒`
- 特写动作细节：`0.8 - 2.0秒`
- 动作爆发 / 对撞 / 闪避：`0.6 - 1.8秒`
- 转身 / 回头 / 停顿：`1.0 - 2.5秒`
