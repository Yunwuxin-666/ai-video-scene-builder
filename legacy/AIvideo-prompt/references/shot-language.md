# Shot Language

Keep only the lens-language ideas that directly affect execution.

## Core Dimensions

- 景别
- 机位
- 构图
- 运镜
- 节奏
- 轴线
- 视线匹配
- 动作连续性

## Use Them Like This

### 景别
Controls information distance:

- far shot for space and isolation
- medium shot for state and action
- close shot for expression
- detail shot for emotional anchor

### 机位
Controls the viewer’s position:

- eye-level for neutrality
- high angle for fragility
- low angle for pressure, weight, or presence

### 构图
Controls where attention lands first.

### 运镜
Controls how attention moves over time.

### 节奏
Controls when information arrives and how long emotion stays.

### 轴线 / 视线 / 动作连续性
These control whether multiple shots still feel like one coherent scene.

## Important Reminder

Shot language is not there to make the scene “more professional”.
It is there to control:

- what the audience notices first
- what the audience feels first
- how time and space are reorganized for storytelling
