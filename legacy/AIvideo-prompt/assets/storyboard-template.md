# 分镜输出模板

当前默认分镜输出使用四块结构，而不是单独一张传统分镜表。

## 标准结构

```markdown
【基础设定】

角色1：
[身份 + 体型 + 时代/风格 + 自主意识/性格 + 脸部/表情系统 + 服装/机体/材质 + 固定道具]

角色2：
[对手/搭档/怪物/道具角色，写清体型、材质、行为特征、危险点或喜剧点]

场景：
[时代 + 地点 + 空间状态 + 可见道具 + 环境破坏 + 时间天气 + 叙事氛围]

声音：
[默认不要配乐，只保留现场声音、动作声、环境声、必要特效声]

【氛围与画质】

风格核心：
[3-6个强风格词，不要泛泛堆词]

视觉强调：
[摄影机/镜头/画幅/运动模糊/实拍质感/是否禁止廉价CG感]

色彩与影调：
[时代美学 + 主色组合 + 饱和度 + 胶片颗粒 + 高光暗部策略 + 材质清晰度]

视觉案例：
[把参考作品/IP转成中性可见风格，不直接写平台可能限制的专有名词，除非用户明确要求保留]

【画面内容】

分镜

分镜 1（00:00-00:03）【景别/镜头类型】
[机位 + 构图 + 画面先看到什么 + 主体动作 + 环境反馈 + 声音/特效重点]

分镜 2（00:03-00:06）【景别/镜头类型】
[继续按时间推进，写动作变化和情绪落点]

【完整分镜脚本表】

| 镜头号 | 时间码 | 时长 | 景别 | 机位 | 画面内容 | 动作 | 情绪目的 | 声音提示 | 镜头功能 |
|---:|---|---:|---|---|---|---|---|---|---|
| 1 | 00:00-00:03 | 3.0s |  |  |  |  |  |  |  |
```

## 只要表格时

如果用户明确要求 `只要表格`、`只要分镜脚本表`、`CSV` 或 `Markdown 表格`，使用完整 10 列表格：

| 镜头号 | 时长 | 景别 | 机位 | 画面内容 | 动作 | 情绪目的 | 声音提示 | 全局提示词 | 细节增强提示词 |
|---|---:|---|---|---|---|---|---|---|---|
| 1 | 3.6秒 |  |  |  |  |  |  |  |  |

## 写法要求

- `时长` 默认支持 `0.1秒` 粒度，优先允许写成 `2.4秒`、`3.2秒`、`0.8秒`。
- 不要默认把所有镜头都四舍五入成整数秒。
- `画面内容` 不能只写成一句空泛摘要。
- `画面内容` 要能支撑后续出图、出视频、做课件。
- `【画面内容】` 的每个分镜段落必须带时间戳。
- `【完整分镜脚本表】` 只结构化同一批镜头，不新增剧情。

`画面内容` 尽量写清：

- 人物是谁，在画面什么位置
- 人物从哪个方向出场
- 人物彼此在左 / 右 / 前 / 后 / 高 / 低的关系
- 谁更靠近镜头
- 环境在做什么
- 镜头里先看到什么
- 具体动作或结果是什么
- 环境或特效反馈是什么

如果是打斗、追逐、特效、机甲、奇幻、科幻场景，`画面内容` 还要尽量写清：

- 角色初始站位和结束站位
- 特效从哪里出现
- 特效是什么形态
- 特效往哪里走
- 特效打到哪里
- 特效造成了什么环境反馈
- 人物相对位置
- 动作方向
- 攻击或受力点
- 环境是否构成危险
- 前景 / 中景 / 后景里最重要的视觉关系

## 声音要求

- 默认只写现场声音、动作声、环境声、必要特效声。
- 不要默认写背景音乐、配乐、BGM、收尾音乐。
- 声音要服务叙事和反差，不只是补环境。

## 可参考的默认时长范围

- 建立镜头：`2.5 - 4.5秒`
- 中景推进：`2.0 - 3.5秒`
- 近景情绪反应：`1.2 - 2.8秒`
- 特写动作细节：`0.8 - 2.0秒`
- 动作爆发 / 对撞 / 闪避：`0.6 - 1.8秒`
- 转身 / 回头 / 停顿：`1.0 - 2.5秒`
