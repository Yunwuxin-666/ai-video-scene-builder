# Seedance 分组提示词模板

当用户明确要 `Seedance` 输出时，优先按“分组片段”来写，而不是整场戏一条长 prompt。

默认参考来源：

- `.claude/skills/seedance`

## 推荐结构

### 片段 A：一句话功能
- 说明这一组镜头在整场戏里的作用

### Seedance 提示词
```text
【镜头类型】+【主体】+【动作】+【风格】+【运镜】+【声音提示】
```

## 编写规则

- 每组建议控制在 `3-6秒`
- 单组最长不超过 `15秒`
- 每组尽量只承载一个主动作，或一组紧密相连的动作节拍
- 保持时间顺序明确
- 不要把分镜表原句机械拼接成提示词
- 要重写成更适合视频模型理解的中文提示词
- 最终中文措辞优先参考 `.claude/skills/seedance`

## 动作类片段

优先写清：
- 谁在前，谁在后
- 动作先后顺序
- 力量打在哪
- 谁失衡，谁回控，谁反击

## 特效类片段

优先写清：
- 特效来源
- 特效形态
- 特效路径
- 命中或落点
- 余波和环境反馈

## 连续性提醒

如有必要，在每组后补一行：
- 角色一致性提醒
- 装甲状态承接提醒
- 动作方向承接提醒
- 特效余波承接提醒
