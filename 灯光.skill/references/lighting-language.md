# Lighting Language

Use this reference to choose and describe light like a working cinematographer or gaffer.

## Functional Lights

| Type | Function | Use When | Prompt Language |
|---|---|---|---|
| 主光 Key Light | Defines face, subject, and emotional baseline | Any character, interview, ad, or product scene | 左侧柔和主光 / hard side key / warm window key |
| 辅光 Fill Light | Controls shadow density | Need detail without flattening | 低强度辅光保留暗部细节 / low fill ratio |
| 轮廓光 Rim / Back Light | Separates subject from background | Dark background, night, stage, hero/product reveal | 后方冷色轮廓光勾勒肩线 / rim light |
| 背景光 Background Light | Gives depth and environment | Interview, interior, product, studio | 背景墙有柔和渐变光 / warm gradient wall light |
| 实景光 Practical Light | Motivates light inside frame | Lamp, neon, candle, screen, car, street | 暖色台灯作为可见光源 / practical lamp |
| 环境光 Ambient Light | Sets base exposure | Overcast, office, realism, documentary | 阴天散射环境光 / soft ambient skylight |
| 效果光 Effect Light | Simulates event or rhythm | Police light, fire, TV flicker, lightning, vehicle sweep | 红蓝警灯间歇扫过 / flickering firelight |

## Direction

| Direction | Visual Result | Best For | Avoid When |
|---|---|---|---|
| 正面光 Front Key | Clean, readable, low shadow | Beauty, education, clean ads | Need mystery, texture, pressure |
| 侧光 Side Key | Structure, depth, partial concealment | Drama, founder interview, noir, texture | Need friendly high-key clarity |
| 逆光 Back Key | Silhouette, separation, spectacle | Hero entrance, mystery, night, haze beams | Need clear facial emotion |
| 顶光 Overhead | Pressure, institutional realism, fatigue | Interrogation, hospital, factory, subway | Beauty or warm human scenes |
| 底光 Underlight | Unnatural, unsettling, horror | Horror, flashlight, firelight distortion | Normal realism or beauty |
| 斜后方 Kicker | Edge highlight and material sparkle | Product, face contour, luxury ad | Naturalistic scenes with no source |

## Quality

- **Hard light**: crisp shadow edge, sharp texture, high tension. Use for noon sun, thriller, noir blinds, action, interrogation, strong product speculars.
- **Soft light**: gradual shadow edge, flattering skin, emotional gentleness. Use for beauty, interview, education, family, natural window light, premium lifestyle.
- **Bounced light**: realistic soft return from wall/floor/reflector. Use when light should feel invisible and natural.
- **Diffused light**: softened direct source through silk, curtain, softbox, haze, cloud.
- **Negative fill**: subtracts light on shadow side, increasing contrast while keeping realism.

## Contrast

| Look | Key-to-Fill Logic | Use |
|---|---|---|
| High Key | Fill close to key, shallow shadows | Comedy, beauty, clean course video, lifestyle |
| Medium Contrast | Clear key direction with readable shadows | Interview, documentary, brand story |
| Low Key | Key dominates, dark areas large but controlled | Suspense, premium brand, noir, psychological drama |
| Silhouette | Backlight dominates, front exposure minimal | Mystery, reveal, farewell, epic frame |

## Color Temperature

- Warm light: tungsten, candle, sunset, lamp, fire, intimacy, memory, hospitality.
- Cool light: moon, overcast sky, screen, hospital, tech, loneliness, night city.
- Warm/cool contrast: use to separate interior/exterior, human/urban, private/public, safety/danger.
- Keep mixed color motivated. Do not use color contrast just because it sounds cinematic.

## Classic Setups

### Three-Point Lighting

Use `主光 + 辅光 + 轮廓光`. Good for interviews, courses, presenter videos, product intros. Keep ratios unequal so the image does not look flat.

### Rembrandt Lighting

Side-front key creates a small triangle on the shadow cheek. Good for portraits, serious interviews, artists, founders, historical tone.

### Butterfly Lighting

Soft front-top key creates a small shadow under the nose. Good for beauty, fashion, celebrity, makeup, clean brand portraits.

### Split Lighting

Half face bright, half face dark. Good for double identity, moral conflict, villain, suspense.

### Motivated Practical Setup

Start with a visible lamp, window, screen, neon, candle, or streetlight, then reinforce it with off-camera key/fill. Use for believable night interiors and cinematic realism.
