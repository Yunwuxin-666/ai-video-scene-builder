# Film workflow scoring rubric

Use `../references/quality-scorecard.md` as the scoring authority. Do not duplicate or weaken its live-delivery thresholds in eval results.

## Stability run

Run each case at least five times. Compare:

- locked-field drift;
- premise and ending drift;
- shot-count variance;
- reference-role mistakes;
- visual-route leakage;
- first-pass gate rate;
- prompt length and duplicate information.
